# Page covers — paste into Notion

Copy everything inside one page's code block and paste it inside that page's cover callout (the first block on the page). Notion turns each line into a block (the lines have no blank lines between them on purpose — an empty block inside the cover shifts the layout): two texts, a Heading 1, the lede, and the bottom two texts.

Markdown can't make callouts or columns, so the buttons are added by hand: copy the button pair (the column list with the Green and Gray callouts) and drop it between the lede and the "Genesis onward" line. Then change the second button's label and link.
